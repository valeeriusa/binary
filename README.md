# Binary OS - Modern Desktop Environment

A complete operating system interface built with modern web technologies, featuring a clean and intuitive design that mimics a real desktop environment.

## 🎯 Features

### Desktop Environment
- **Animated Background**: Beautiful gradient background with smooth color transitions
- **Desktop Icons**: Clickable application shortcuts with hover effects
- **Taskbar**: Full-featured taskbar with start menu, running apps, and system tray
- **System Tray**: Real-time clock, date, and system status indicators

### Window Management
- **Draggable Windows**: Move windows around the desktop by dragging the title bar
- **Window Controls**: Minimize, maximize, and close buttons like a real OS
- **Multiple Windows**: Run multiple applications simultaneously
- **Z-Index Management**: Click to bring windows to front
- **Taskbar Integration**: Running apps appear in taskbar with click-to-restore functionality

### Applications

#### 🖥️ Terminal
- Fully functional command-line interface
- Built-in commands: `help`, `clear`, `ls`, `pwd`, `whoami`, `date`, `echo`, `neofetch`
- Interactive cursor and command history
- Authentic terminal look and feel

#### 📁 File Manager
- Two-panel file browser interface
- Quick access sidebar with common folders
- File and folder icons
- Hover effects and modern UI

#### ✏️ Text Editor
- Code editor with syntax highlighting support
- File operations (New, Save, Save As)
- Monospace font for coding
- Sample code included

#### 🧮 Calculator
- Fully functional calculator with modern design
- Basic arithmetic operations (+, -, ×, ÷)
- Percentage and sign change functions
- Scientific calculator styling

#### 🌐 Web Browser
- Simulated browser interface
- Address bar and navigation buttons
- Modern browser-like experience
- Sample content page

#### ⚙️ Settings
- System settings interface
- Display configuration options
- Brightness control and resolution settings
- Toggle switches for system preferences

### Start Menu
- Modern application launcher
- User profile section
- Categorized applications
- System controls (Shutdown, Restart, Logout)
- Smooth animations and transitions

### Boot Sequence
- Authentic boot screen with loading animation
- Binary OS branding and loading indicators
- Smooth transition to desktop

## 🚀 Getting Started

1. **Local Development**:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

2. **Usage**:
   - **Double-click** desktop icons to open applications
   - **Click** the "Binary" button to open the start menu
   - **Drag** windows by their title bars
   - **Use window controls** to minimize, maximize, or close windows
   - **Type commands** in the terminal when it's focused
   - **Click taskbar apps** to restore minimized windows
